# Mundo Aberto 3D

Jogo Android de mundo aberto com OpenGL ES 2.0, auras e poderes.

## Status atual

O projeto **já gera APK**. No momento está com um placeholder (tela de texto).

Para ter o **jogo completo** (terreno, auras, poderes, inimigos, etc.) você precisa colocar o `MainActivity.java` original.

## Como colocar o jogo completo e gerar o APK

1. Abra este link de upload:
   https://github.com/mrbarros032-gif/mundo-aberto/upload/main/app/src/main/java/com/test/games

2. Arraste o arquivo **MainActivity.java** completo (o original de ~340 KB) para a página.

3. Escreva a mensagem de commit (ex: `jogo completo`) e clique em **Commit changes**.

4. Vá na aba **Actions** → **Build APK** → **Run workflow** → **Run workflow**.

5. Quando ficar verde, baixe o artefato **MundoAberto-APK** e instale no celular.

Pronto. O APK do jogo real sai dali.
