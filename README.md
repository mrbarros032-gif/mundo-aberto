# Mundo Aberto 3D

Jogo Android de mundo aberto com OpenGL ES 2.0, auras e poderes.

## Como gerar o APK

1. Faça o **upload** do arquivo `MainActivity.java` completo para o caminho:
   
   `app/src/main/java/com/test/games/MainActivity.java`

   (substitua o arquivo placeholder atual)

2. Vá na aba **Actions** do repositório.

3. Clique em **Build APK** → **Run workflow** → **Run workflow**.

4. Quando o build terminar (verde), baixe o artefato **MundoAberto-APK**.

5. Instale o `.apk` no celular (ative "Fontes desconhecidas" se necessário).
